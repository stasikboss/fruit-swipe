# הפירות שלי

משחק חיתוך פירות רגוע לילדים בגילאי 3 עד 6, עם ירח שמדבר בעברית, ברוסית ובאנגלית.

- `index.html`: דף ההורדה. מזהה אייפון, גלקסי, דפדפן פנימי של פייסבוק או מחשב, ומראה את שלבי ההתקנה המתאימים.
- `play.html`: המשחק עצמו.
- `sw.js`: שומר את המשחק במכשיר כדי שיעבוד גם בלי אינטרנט.

בלי פרסומות, בלי הרשמה ובלי איסוף מידע. ההגדרות נשמרות רק במכשיר.
